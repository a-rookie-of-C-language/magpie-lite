        One model=window in tokens per line. A routing group leaves out a member whose known window cannot hold the request, instead of asking it and failing there. A model without a window is always tried.

        Saved keys are never displayed. Choose Replace to rotate credentials, or No upstream authentication for a local service.

        One API key per line, in rotation order. These values are sent when you save, discover models or test a connection.

        Rotate spreads requests across the key pool, the default. Ordered always starts at the first key. Least used prefers the key that served the fewest tokens lately. Weighted spreads by each key's weight.

        Keep a conversation on the key that answered it so the vendor's prompt cache keeps hitting. Auto follows the key routing: rotate spreads load, everything else sticks by conversation.

        One weight per key slot, in pool order, each a whole number from 0 to 1000. A missing or zero weight counts as 1.
